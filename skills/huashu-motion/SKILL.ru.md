# huashu-motion — инструкция на русском

Это русскоязычное руководство к неофициальному форку. Полная исходная инструкция автора сохранена в [SKILL.md](SKILL.md); подробные справочники в references/ остаются оригинальными. При уточнении технического контракта используй также [CONTRACT.md](../../../docs/CONTRACT.md).

Ты одновременно режиссёр, дизайнер и аниматор. Результат — один фильм index.html: HTML/GSAP, покадровый рендер в установленном Chrome, редактируемые тексты/цвета и обратная связь на конкретном кадре. Рабочая программа ещё не означает удачный фильм: оцени реальные кадры, ритм и звук.

## Команды

Запускай `node <папка-репозитория>/cli/om.js <команда>`. Нужны Node22+,Chrome,FFmpeg/ffprobe.

| Команда | Назначение |
|---|---|
| `grab <папка или URL> <проект>` | Собрать настоящие материалы продукта |
| `new <проект>` | Создать чистую композицию |
| `studio <проект> --no-open` | Запустить русский локальный редактор |
| `inbox <проект> --wait` | Получить комментарий на кадре |
| `look <id> <проект>` | Увидеть кадр и отмеченную область |
| `done <id> <проект> --note "…"` | Ответить на обработанный комментарий |
| `set key=value <проект>` | Изменить редактируемое поле |
| `sound <проект>` | Создать музыку и эффекты из деклараций |
| `samples` / `samples build` | Проверить / установить пакет настоящих инструментов |
| `voice <проект> --text script.txt` | Речь и временные метки слов, если речь нужна |
| `check <проект>` | Проверить код, материалы, геометрию и переходы |
| `still <проект> --at 0,2.5` | Получить реальные ключевые кадры |
| `render <проект>` | Собрать новый MP4 в out/ |
| `qa <проект>` | Проверить готовое видео |
| `share <проект>` | Подготовить GIFдо10MiB и текст публикации |
| `learn launch rhythm sound` | Прочитать опыт перед работой |
| `learn harvest <проект>` | Разобрать уроки завершённой работы |
| `undo <проект>` | Вернуть предыдущий исходник |

Вызовы Chrome и локального сервера могут требовать разрешённого запуска вне песочницы. Не подменяй отсутствующий визуальный просмотр словами об успешной проверке. Правила и разрешения пользователя выше рекомендаций этого навыка.

## Порядок работы

1. **Сначала продукт и режиссура.** Выполни learn и прочитай [director.md](references/director.md), затем подходящие разделы [библиотеки](references/library/README.md). Изучи реальные файлы, интерфейс, цвета, шрифты, записи и назначение продукта. Запиши одну мысль, которую зритель должен запомнить. До предложения стиля собери materials/ и materials.md с происхождением и лицензиями. Логотип используй настоящий; интерфейс и данные не выдумывай. Выявленные личные данные исключи из кадров.
2. **Определи формат, характер и речь.** Если их нельзя вывести из задания, предложи разумные значения и несколько узнаваемых альтернатив одним коротким сообщением. Речь согласуй один раз: без диктора / системный голос / запись пользователя. По умолчанию музыка и эффекты. При кратком запросе возьми энергичный старт: предмет фильма уже в кадре0, смысловой крючок до3сек, первый яркий момент до5сек. Спокойный старт допустим по художественному решению или просьбе пользователя.
3. **Три направления.** Покажи три разных визуальных языка на настоящих материалах, по одному реальному ключевому кадру и короткой карточке с палитрой/источником. Один вариант — объёмный, если задание этого не исключает. Различай композицию и движение, а не только цвет. Если стиль уже выбран пользователем, этот этап можно пропустить. Музыкальный характер выбери из продукта и зафиксируй в treatment; не заставляй выбирать музыку по неподвижным карточкам.
4. **Treatment до полной сборки.** Запиши treatment.md: маршрут, ритмический план, изменения энергии, склейки, четыре опорных кадра и причинную связь сцен. Прочитай [rhythm.md](references/rhythm.md), [colour.md](references/colour.md), файл выбранного визуального языка и [техники](references/library/techniques.md). У каждой сцены должен быть смысловой глагол; украшение без объяснения не заменяет материал продукта.
5. **Сначала сложнейший кадр.** Создай new или подходящий шаблон, доведи главный момент до нужного качества, затем собирай остальные. Синхронные акценты задавай рядом с моментом приземления через OM.sfx; музыкальные доли — через OM.music и OM.beat. Строй контраст: нарастание, всплеск, короткая пауза и пик, если они помогают именно этому фильму.
6. **Проверяй видимый результат.** check должен завершиться без ошибок. still — все ключевые моменты и первую секунду после каждой склейки. Проверь обрезанный текст, наложения, пустые кадры, читаемость на телефоне и корректность покадрового перехода. До выдачи первого полного рендера посмотри его в обычной скорости или дай независимому агенту холодный разбор. Запиши три сильнейших замечания и исправь их. Не называй проверку кадров полным просмотром со звуком.
7. **Музыка и эффекты.** Для полноценного проморолика напиши свою ABC-партитуру om-score под сцены; встроенный музыкальный стиль — быстрый запасной вариант. Мотив, инструменты, темп и регистры должны подходить продукту. Не копируй состав инструментов из прошлого фильма или примера. Примерно8–15значимых акцентов на30сек; не озвучивай каждый декоративный элемент. Запускай sound после изменения таймингов. С речью сначала voice, затем sound с приглушением музыки. Если не можешь слушать, проверь спектр/уровни и явно сохраняй это ограничение оценки.
8. **Редактор и обратная связь.** Запусти studio, передай URL. Комментарии содержат время, сцену, элемент и место в исходнике. Перед изменением выполни look; правь именно указанное место, сохраняя стабильные идентификаторы. Простые значения меняй через set. Уточняй только существенную неоднозначность. Закрывай done с короткой русской заметкой, что изменилось. История/undo должны сохраняться.
9. **Экспорт и передача.** Собирай render, затем qa по готовому файлу. Устрани одиночные вспышки, непредусмотренные пустоты и паузы. Малоподвижные моменты по заданию не являются автоматическим дефектом. --blur применяй, если быстрое движение нуждается в нём; для пиксельной графики оцени, не размывает ли он рисунок. После share перепиши share.md на язык пользователя: о чём фильм и одна конкретная деталь создания. Передай MP4,GIFи текст. Самостоятельно публиковать их навык не разрешает.
10. **Сохрани опыт.** После принятия или прекращения правок выполни learn harvest. Пользовательские предпочтения, наблюдения одного фильма и подтверждённые измерения записывай раздельно. Не делай всеобщего правила из вкуса одного человека; опыт не расширяет разрешения на публикацию, расходы или контакты.

## Контракт композиции

- В корне проекта ровно один HTML-фильм. Черновики и направления — в подпапках.
- Один paused GSAP timeline в `window.__timelines[id]`. Время должно определять весь видимый результат: без Date.now, нефиксированного random, сетевых материалов и накопительных callback-состояний.
- Изменяемые тексты, числа, цвета, длительности и данные — `data-composition-variables` на html. Связи: `data-var-text`,CSS var,OM.vars; динамический текст помечай `data-om-var`.
- Всё, на что пользователь может указать, имеет стабильный `data-om-id`. Для canvas/WebGL добавляй OM.region. Сцены — `tl.addLabel('scene:name',time)`.
- Звук декларативен: OM.sfx + собственная партитура `<script type="text/vnd.abc" id="om-score">` и/или OM.music. `om sound` пересоздаёт assets/sound.wav; не редактируй его вручную. После сдвига видео пересвязывай соответствующий звук.
- Анимируй transforms, не left/top/width/height. Исключения для намеренных пересечений помечай `data-layout-allow-*` и проверяй глазами.
- Все шрифты/библиотеки/материалы локальные. Для случайности используй OM.random(seed), для canvas — OM.clock, для камеры — OM.camera/OM.space, когда она соответствует заданию.
- Фиксируй data-duration только при фиксированной длительности поставки; иначе timeline определяет конец и редактируемое удержание.
- Фильм длительнее4сек заканчивается маленькой подписью Made with huashu-motion на последних1,2сек в свободном углу, шрифтом и цветом фильма. Отключай data-om-signature="off" по просьбе пользователя или при оплаченной клиентской работе от лица заказчика. Оверлеи подписи не содержат. При передаче упомяни её и возможность отключения.
