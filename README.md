# huashu-motion — русский редактор

Неофициальный русскоязычный форк [huashu-motion](https://github.com/alchaincyf/huashu-motion) автора Huashu (花叔). Основан на полной версии0.3.1, исходный коммит `52467f99c602b76ba86d511d37acdfe93fa1e16e`. Авторство и лицензия MIT сохранены.

Агент создаёт ролик как HTML/GSAP-композицию, пишет музыку и собирает MP4 в локальном Chrome. В редакторе можно менять тексты и цвета, оставлять комментарии прямо на кадре, возвращать предыдущую версию и экспортировать видео.

## Что переведено

- Интерфейс Studio: панели, кнопки, подсказки, комментарии, статусы, шкала и сообщения экспорта.
- Подписи доступности встроенного плеера.
- Это руководство и [инструкция для агента](skills/huashu-motion/SKILL.ru.md).
- Добавлены «Сохранить», ⌘S/Ctrl+S и последовательная отправка правок. Поля также сохраняются при завершении редактирования. Быстрые правки не отправляются с одним устаревшим токеном.

Команды CLI, технические ошибки, исходные справочники и примеры сохранены на языке upstream. Полная исходная библиотека, тесты и документация включены. Игровые материалы, личные файлы и проекты в этот форк не входят.

## Установка

Нужны Node.js22+, Chrome/Chromium и FFmpeg с ffprobe. Платные API для локального рендера и синтезированной музыки не нужны.

```sh
git clone https://github.com/korkinss1-ops/huashu-motion-ru.git
cd huashu-motion-ru
node cli/om.js doctor
node cli/om.js new ../my-film
node cli/om.js studio ../my-film --no-open
```

Открой адрес, который напечатает команда; обычно это `http://127.0.0.1:4848/`. Сервер работает только на локальном компьютере. Окно терминала должно оставаться открытым.

Установить навык для своего агента:

```sh
npx skills add korkinss1-ops/huashu-motion-ru
```

Основной SKILL.md и оригинальные справочники сохранены для совместимости с upstream; русская инструкция доступна рядом. Укажи агенту использовать этот форк и SKILL.ru.md, если нужен русский рабочий процесс.

## Как редактировать

1. Выбери время на шкале. Пробел — пуск/пауза, стрелки — один кадр, Shift+стрелка — секунда.
2. Измени поле справа и нажми «Сохранить» или ⌘S/Ctrl+S. Двойной щелчок по тексту на кадре меняет связанное поле напрямую.
3. «Отменить» / ⌘Z / Ctrl+Z возвращает предыдущую сохранённую композицию. История находится в `.om/` проекта.
4. Нажми C и укажи место на кадре, чтобы оставить комментарий агенту. Комментарий сам по себе не запускает агента: напиши в его чате «Обработай комментарии huashu-motion».
5. «Экспорт видео» создаёт новый файл в `out/`, сохраняя предыдущие экспорты.

Параметры появляются, если агент объявил `data-composition-variables`. Перестановка сцен и замена исходных клипов выполняются агентом в композиции; шкала предназначена для просмотра и навигации.

## Проверка и экспорт

```sh
node cli/om.js check ../my-film
node cli/om.js sound ../my-film
node cli/om.js render ../my-film
node cli/om.js qa ../my-film
node cli/om.js share ../my-film
npm test
```

Музыка и эффекты задаются в исходнике через `om-score`, `OM.music` и `OM.sfx`. После изменения таймингов повтори `om sound`; штатный экспорт также обновляет объявленный звук. Исходники фильма, его музыка и лицензии материалов принадлежат отдельному проекту.

## Обновление от оригинала

```sh
git remote add upstream https://github.com/alchaincyf/huashu-motion.git
git fetch upstream
git diff HEAD..upstream/main
```
